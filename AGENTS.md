# Genoma — MVA Hackathon DSPy Pipeline

## Purpose

DSPy pipeline for the **Rare Disease, Real Kid: MVA Hackathon 2026**: Track 1 (variant prediction, auto-scored rank points + F-max) and Track 2 (drug repurposing, expert-judged). Built on **dspy==3.3.1** (pinned — ReActV2 renames in 3.5).

## Ownership

Agent-maintained scaffold. Source of truth for DSPy API choices: `../research/DSPY_3.3.1_SOURCE_VERIFIED.md` (source-verified; docs lag).

## Local Contracts

- **uv project** (not pip). `uv sync` + `./run.sh <cmd>` (run.sh prepends the NixOS gcc `libstdc++` path for litellm/tokenizers).
- **`.env`** holds secrets (HF_TOKEN, ANTHROPIC_API_KEY, OPENROUTER_API_KEY) — never committed.
- **`data/`** = gated dataset (VCF + phenotype docx). Never commit. Must be deleted within 30 days of hackathon close (2026-10-24 23:59 UTC).
- **Key API choices (verified against 3.3.1 source):** RLM (not deprecated POT/CodeAct) with **sandbox domain tools** (`RLM(tools=[mechanism_lookup, known_mva_gene, gene_prior_fraction])` — host-side, injected into the interpreter, don't consume the LLM-call budget); custom panel consensus (no `dspy.Ensemble` module; `majority` wrong for float EPCR; **weighted** median/trimmed-mean honors the declared `PANEL` weights — claude-sonnet-5 at 2.0x — plus spread-triggered debate and post-debate abstention); GEPA 5-arg judge metric returning `Prediction(score, feedback)`; BAMLAdapter (2.4x smaller schema prompts on list types) as the default structured adapter; **`configure_cache(restrict_pickle=True, safe_types=dspy.core.types.*)`** hardens the disk cache (LM responses are stored verbatim — out-of-allowlist entries are deleted, degrade to a cache miss, never crash); Track 2 tools wrapped as explicit `dspy.Tool` (richer native-function-calling schema).
- **Scoring is differentially tested against the official scorer**: `tests/test_official_parity.py` imports `../mva-hackathon-2026/evaluation.py` and asserts byte-identical rank points + F-max. Full match = compound-het pair in ONE row.
- **External genomics tools — fail fast, no silent fallbacks**: VEP local annotation (vep_data/vep_run.sh — podman official image, release_110.0; `vcf_path()` consumes `data/annotated.vcf.gz` when present, CSQ named-field parser in annotate.py; run with `--user 0` so rootless podman can write into `data/`; do NOT pass `--no_sv` — VEP 110 does not recognize it, SV annotation is off by default), WhatsHap read-backed phasing (data/phasing.py — trans/cis from PS/HP/GT tags, default WhatsHap `--tag=PS` GT-format supported + pipeline generator), **trio Mendelian phasing** (deterministic trans/cis from parental genotypes when the VCF carries family samples — `trio_phase_pairs` overrides tag-based when informative; single-proband VCFs fall back to unknown), Exomiser comp-het mode (data/exomiser.py — phenopacket YAML + `merge_exomiser_scores` couples gene-level scores onto candidates, raises a clear error if Java/EXOMISER_JAR absent), Phen2Gene HPO→gene ranking (data/phen2gene.py — REST API only; API/parse errors propagate; `_fallback_ranking()` is an explicit offline prior, never auto-substituted). VEP REST enrichment (data/annotate.py) also pulls **REVEL + AlphaMissense + SpliceAI + CADD** via query-string params (`?REVEL=1;AlphaMissense=1;CADD=snv_indels;SpliceAI=2` — verified 2026-08-30: predictors go in the URL, NOT the JSON body) and fails fast.
- **Transient-HTTP retry is fail-fast compatible** — `net.py.urlopen_with_retry` (used by VEP, Phen2Gene, and all Track 2 tools) retries ONLY 429/500/502/503/504 + URLError/timeout with exponential backoff; 4xx raises immediately and exhausted retries re-raise. No silent fallback, ever.
- **Track 2 emits a review artifact** — `track2/report.py` writes `submission/track2_report.md` (drug → mechanism → pathway rationale → evidence → risks + methods/disclaimer) AND `submission/track2_methods_report.md` (all 11 methods-template questions); Track 2 is expert-judged, so the written reports are the submission, not console output. Track 1 `track1/report.py` answers all 11 Track 1 template questions (incl. the required Generative-AI disclosure). `docs/PITCH_SCRIPT.md` is the 3-minute pitch script.

## Work Guidance

- Demo mode runs offline via DummyLM: `./run.sh demo` (no keys, no data).
- Real runs need: HF token + terms accepted (dataset gated), ANTHROPIC_API_KEY, then `./run.sh ingest` → `score` / `panel` / `track2`. Follow `docs/LIVE_RUNBOOK.md` for the exact sequence + the 6-submission feedback-oracle loop.
- Config knobs for real-run scale (SSOT): `CANDIDATE_MAX_DEFAULT=2000` (candidate-pool cap) and `COMPHET_MAX_PAIRS=50` (compound-het pairs) — both were hardcoded smaller; the real genome-wide AR run needs the headroom so a novel causal gene's pair can never be truncated out of the pool. `./run.sh cost` reflects these defaults.
- `ingest` runs a storage preflight: HF-reported file sizes (+20% headroom) vs free disk at DATA_DIR — fails fast with numbers instead of dying mid-download. The .tbi index ships with the download (cyvcf2 needs it for region queries).
- GEPA judge balance is a CLI knob: `optimize --judge-cls-weight W` (calibration = 1−W; default 0.7). If noisy-data optimization degrades EPCR fit, raise W toward robust reasoning; `evaluate --judge-cls-weight W` must match for comparable scores.
- Anthropic prompt caching: wired via `PRIMARY_LM_KWARGS.cache_control_injection_points` (system + last message); the BAML adapter's static schema/instructions prefix is what gets cached across parallel candidate scoring.
- **Client-side token-bucket rate limiting** — `lm.py` wraps every LM in `RateLimitedLM` (subclass of dspy.LM): it estimates input tokens per request and delays host-side to stay under the per-minute budget. Set `LM_TPM` (env or config; 0 = unlimited) so high-volume parallel runs avoid provider 429s / Tier-limit blocks *before* they happen, instead of retrying after.
- **HPO extraction is negation-aware + semantic** — phenotype-sheet rows carrying exclusion markers (none / not observed / absent / negative / denied / ruled out / excluded / no) are skipped; free-text lines without HP: ids are mapped through an offline stemmed synonym table (`_semantic_hpo_match`: "small head" → Microcephaly, "developmental lag" → Global developmental delay) — dependency-free, no model download.
- Compliance: `./run.sh compliance` prints the deletion checklist; `./run.sh purge-cache` clears the DSPy disk cache (~/.dspy_cache, LM responses verbatim) **plus DATA_DIR (gated VCF/docx + data/.cache/huggingface blobs) and this dataset's HF hub-cache entry** (`--keep-data` to skip).
- **Genome assembly is SSOT in config** — `GENOME_ASSEMBLY = "GRCh38"` (challenge schema + VEP REST default) and `EXOMISER_ASSEMBLY = "hg38"` (same build, Exomiser's token); the analysis YAML fills `genomeAssembly` from config, never hardcoded.
- **VCF contigs are normalized to `chrN` at the ingest boundary** — the challenge VCF carries bare contigs (`1`..`22`, `X`, `Y`, `M`) but the official scorer compares chromosome strings verbatim in `chrN` form (`chr2`, `chr15`); `load_vcf_records` (`ingest.py::_normalize_chrom`) prefixes `chr` (and maps `M`/`MT`→`chrM`) so candidate tables, phasing/annot-cache keys, and submission rows all agree with the ground truth. Never emit bare-contig coordinates in a submission.
- **Gene prior is boost-only** — `apply_gene_prior` lifts known MVA genes toward 1.0 and NEVER penalizes unlisted genes: a highly pathogenic variant in a novel SAC/mitotic gene (BUB3, MAD2L1, MPS1/TTK) keeps its raw EPCR and can surface at rank 1 (regression-tested end-to-end through calibration). LM-side retries: `num_retries=3` on every LM (litellm 429 backoff); REST-side: `net.urlopen_with_retry` defaults (4 attempts, 2.0s base ×1.5 ≈ 9.5s) survive a burst from the 8-thread parallel scorer.
- **Candidate pool is genome-aware, not VCF-order** — the challenge VCF's first N records are all chr1, so a naive cap would truncate a causal gene on a late chromosome (BUB1B is chr15). `build_candidate_table` selects by `_selection_priority`: protein-altering known-gene variants (LOF/missense/splice) always enter the capped pool, then protein-altering variants in ANY gene (novel causal candidates never truncated), then non-coding known-gene, then fillers. Regression-tested (`test_pool_selection_is_genome_aware_not_vcf_order`).
- **Sample genotype AF is never treated as population AF** — the challenge VCF carries `AC=1;AF=0.5;AN=2` (the proband's own het genotype); `_extract_af` ignores bare `AF` whenever AC/AN genotype context is present, honoring only true population fields (`gnomAD_AF`/`MAX_AF`/`INFO_AF`/`AF_popmax`, or bare `AF` on a VCF with no genotype fields). Reading sample AF as population AF would flag every variant as "common" and drop the causal pair. Regression-tested (`test_af_ignores_sample_genotype_frequency`).
- **Track 2 prompt carries therapeutic-window guidance** — the signature steers the agent away from broadly cytotoxic spindle poisons (taxanes/vinca alkaloids — they worsen systemic aneuploidy in a child) toward aneuploid-cell-selective vulnerabilities (proteotoxic stress, HSP90, autophagy) with pediatric safety context; each candidate must state its benefit-risk balance for THIS proband.
- Track 1 submission CSV must match `../mva-hackathon-2026/static/templates/track1_submission_template.csv` schema (validated in `data/submission.py`).
